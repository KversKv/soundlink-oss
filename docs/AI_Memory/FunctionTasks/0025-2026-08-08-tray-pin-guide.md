# 托盘图标常驻引导（在任务栏显示图标…）（2026-08-08）

> 场景：用户反馈 Windows 右下角任务栏图标会被自动隐藏（折叠进角溢出菜单），希望应用能自动设置不隐藏、无需用户手动进系统设置。调研结论：微软无公开 API 供应用自行常驻托盘图标（`Shell_NotifyIcon` 只能增删改图标，可见性是纯用户选择；注册表 `NotifyIconSettings` 强写属未公开 hack、键名为路径哈希易失效）。故采用方案 B——官方推荐的引导路径：托盘菜单加引导项，一键拉起系统设置页 + 前端步骤浮层。

## 关键设计决策

- **为什么不做注册表强写（方案 A）**：`HKCU\Control Panel\NotifyIconSettings` 子键名为 exe 路径的未公开哈希算法，exe 路径变化（更新/重装/MSIX）即失效；且条目须图标出现过一次后才存在，属未公开行为微软随时可改。与项目「最小改动、不引入私有 API」红线相悖。
- **菜单项仅 Windows**：macOS 菜单栏图标无折叠概念，用 `#[cfg(windows)]` 在构建期排除，Linux/macOS 菜单不出现该项。
- **设置页 URI 选 `ms-settings:taskbar`**：Win10/Win11 均有效；Win11 落在任务栏设置页（含「任务栏角溢出」开关列表），是最接近目标的一级页面，微软未提供直达角溢出子页的 URI。
- **复用 `tray-menu-click` 事件通道**：不新增事件名，`TrayMenuEvent` 加变体即可，前端既有监听处加一个分支，改动面最小。

## 已知边界

- 设置页仍需用户亲手打开一次开关（或从角溢出菜单拖拽图标到任务栏），这是 Windows 平台限制，所有应用（含微信/QQ）相同。
- Win10 设置页文案为「选择哪些图标显示在任务栏上」，引导浮层已同时列出两代文案。
