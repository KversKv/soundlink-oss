# 桌面端 UI 仿图改版实录（2026-07-07）

> 场景：用户提供桌面端界面参考图，要求按图片效果更改当前桌面端 UI。

## 背景

- 原桌面 UI 集中在 `desktop/ui/src/App.tsx`，大量使用行内样式。
- 用户参考图为窄窗口卡片式界面：顶部品牌图标、接收/发送分段切换、配对码大卡片、输出设备/Jitter/音量设置、主操作按钮、运行中状态面板和底部阶段提示。
- 桌面端功能接口不变，改版重点是视觉结构与交互状态，不改 Rust/Tauri command。

## 实现清单

| 范围 | 文件 | 变更 |
|---|---|---|
| 桌面 UI 结构 | `desktop/ui/src/App.tsx` | 移除行内样式主布局，重组为品牌头、分段 tab、接收/发送面板、状态卡片和 footer；保留原有 Tauri invoke 与状态逻辑。 |
| 桌面 UI 样式 | `desktop/ui/src/App.css` | 新增仿图样式：蓝色品牌图标、白色内容面板、配对码数字排版、绿色/红色主按钮、运行状态双列数据表、响应式适配；后续按反馈移除最外层嵌入式圆角外壳，让内容铺满窗口。 |
| Tauri 窗口 | `desktop/src-tauri/tauri.conf.json` | 将默认窗口调整为 510×760，设置最小 390×660，使默认打开时接收页不出现滚动条，用户主动缩小时才滚动。 |

## 关键设计决策

- 不引入新依赖，沿用 React + TypeScript + 原生 CSS，降低构建和 Tauri 集成风险。
- 接收端按参考图优先还原；发送端复用同一视觉系统，保持已有双电脑互传功能可用。
- `App.tsx` 只保留交互逻辑和语义结构，视觉细节集中到 `App.css`，便于后续按截图微调。
- 窗口本身作为应用容器，移除页面内二次外壳、外边距、外层投影和外层圆角，避免看起来像嵌入模块。
- 配对码未启动时显示占位横线，设备 ID 未获取时使用视觉占位，避免空状态破坏布局。

## 验证结果

- `npm run build`：通过，TypeScript 与 Vite 构建成功；用户反馈后的铺满窗口调整再次构建通过。
- 浏览器预览 `http://127.0.0.1:1420/`：无前端运行错误。
- IDE 诊断：无 TypeScript/CSS 诊断错误。

## 已知边界

- 默认窗口以未运行接收页不滚动为目标；运行后出现状态卡片时内容高度增加，窗口高度不足仍会按系统滚动行为显示。
- 参考图中的实时运行状态需要后端返回 `status` 后展示；未运行时状态卡片保持隐藏，与原功能一致。
