# 01 · 产品概述（Overview）

## 背景

头戴式耳机用户常希望把手机上的音频（短视频、电影、音乐）通过更好的耳机 / 声卡 / 音箱来听，但手机直连这些设备并不方便。SoundLink 通过局域网把手机音频“流转”到电脑，由电脑负责最终输出。

## 目标用户

- 使用高品质耳机 / 声卡 / 桌面音箱的用户。
- 希望手机内容在电脑音频设备上收听的用户。
- 家庭 / 办公室等**同一局域网**环境。

## 价值主张

- 手机播放什么，电脑就能同步输出到高品质音频设备。
- 快速配对，一次配对后自动连接。
- 合规、可上架，不依赖越狱 / root / 私有 API。
- 可扩展到电脑与电脑之间互传。

## 核心场景

| 场景 | 是否主打 |
|---|---|
| 手机听音乐 → 电脑耳机/声卡 | 是 |
| 手机看电影/长视频 → 电脑输出 | 是 |
| 电脑 A 音频 → 电脑 B 输出 | 是（后续阶段） |
| 短视频（抖音等） | 非主打（延迟可能感知） |
| 游戏 / 连麦 | 不支持（延迟不满足） |

## 非目标（Non-Goals）

- 不做 iOS / Android **全局虚拟声卡**（系统与合规限制）。
- 不兼容非官方 AirPlay 协议。
- 不做后台静默全量音频捕获。
- 不追求超低延迟实时互动场景。
- 第一版不支持 Linux、不支持公网/NAT 穿透（仅局域网）。

## 合规原则

- iOS：仅使用 ReplayKit 官方广播能力，不用私有 API。
- Android：仅使用 MediaProjection / AudioPlaybackCapture 官方能力。
- 明确告知用户：受 DRM / 应用限制的内容可能无法采集。
