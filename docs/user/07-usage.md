# 07 · 使用操作手册

面向最终用户，说明如何把手机音频流转到电脑音频设备。功能随开发阶段逐步可用，见 [`docs/First/09-roadmap.md`](../First/09-roadmap.md)。

## 1. 前提条件

- 手机与电脑处于**同一局域网**（同一路由器 / Wi-Fi，第一版不支持跨网 / 公网）。
- 路由器允许设备间通信（部分“访客网络”或“AP 隔离”会阻断，需关闭隔离）。
- 电脑端已选好目标音频输出设备（耳机 / 声卡 / 音箱）。

## 2. 电脑端（接收）

1. 启动 SoundLink 桌面端。
2. 选择要输出的**音频设备**。
3. 开启接收服务，界面会显示**配对码**与设备名。
4. 保持窗口运行，等待手机连接。

## 3. iOS 手机端（发送）

1. 打开 SoundLink App，在设备列表选中你的电脑（自动发现）。
2. 输入电脑上显示的**配对码**完成配对（首次配对后可自动重连）。
3. 从**控制中心**长按「屏幕录制」→ 选择 **SoundLink** 的广播 → **开始广播**。
4. 播放音乐 / 视频，声音会流转到电脑输出设备。
5. 停止：控制中心再次点击停止广播，或在 App 内断开。

> 注意：受 DRM 保护的内容、部分系统音频可能无法采集。

## 4. Android 手机端（发送）

1. 打开 SoundLink App，选中要连接的电脑。
2. 输入电脑上的**配对码**完成配对。
3. 点击「开始采集」，在系统弹窗中**允许屏幕 / 音频捕获**。
4. 通知栏出现采集状态通知，表示正在流转。
5. 播放音频即可在电脑端听到。
6. 停止：App 内停止，或从通知栏结束采集。

> 注意：仅能采集允许被捕获的应用音频，部分应用 / 受保护内容不可采。

## 5. 电脑到电脑（后续阶段）

一台电脑作为发送端采集系统音频，另一台作为接收端输出。配对流程同上，具体可用性见路线图阶段 5。

## 6. 使用建议

- 追求音画同步时，电脑端建议使用**有线 / USB / 2.4G 低延迟**耳机。
- 本软件面向听音乐 / 看视频等场景；**游戏 / 连麦等实时互动不适用**（延迟不满足）。
- 短视频（如刷抖音）可能感知到轻微延迟，非主打场景。

遇到问题见 [08-troubleshooting.md](./08-troubleshooting.md)。
