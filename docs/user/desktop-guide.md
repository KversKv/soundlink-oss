# SoundLink 桌面端使用指南

> 适用对象：SoundLink 桌面端（Windows）终端用户
> 版本：v0.1.0-beta
> 更新日期：2026-07-12

SoundLink 是一款局域网音频流转软件，支持把手机或电脑的音频通过本地局域网传到另一台电脑播放。本指南面向桌面端终端用户，介绍安装、配对、收发、设置与常见问题排查。

---

## 1. 安装

### 1.1 系统要求

- Windows 10 64 位及以上
- WebView2 Runtime（Windows 10/11 通常已预装；如缺失可从 [微软官网](https://developer.microsoft.com/microsoft-edge/webview2/) 下载）

### 1.2 安装方式

1. 从发布页获取 `SoundLink_x.x.x_x64-setup.exe`。
2. 双击运行安装程序，按提示完成安装。
3. 安装完成后从开始菜单启动 SoundLink。

### 1.3 首次启动

首次启动会弹出**三步引导**：

1. **选择角色**：接收端（用本机播放音频）或发送端（把本机音频传出去）。
2. **选择设备**：
   - 接收端：选择默认音频输出设备（耳机/扬声器）。
   - 发送端：选择默认采集源，并会提示「部分受 DRM 保护的应用音频可能无法采集，属系统限制」。
3. **测试连接**：
   - 接收端：记下配对码，等发送端连接。
   - 发送端：可跳过或直接连接已发现的接收端。

完成后引导不再弹出。后续可在「设置」中重新配置。

## 2. 接收模式（电脑播放音频）

接收模式让本机作为「无线耳机」，播放来自手机或另一台电脑的音频。

### 2.1 开始接收

1. 在主界面顶部确认角色为「接收端」。
2. 点击「开始接收」按钮。
3. 状态卡显示「等待连接」与**配对码**（6 位数字）。

### 2.2 配对

1. 在发送端（手机 App 或另一台电脑）扫描局域网，找到本机设备名。
2. 输入屏幕上的配对码。
3. 配对成功后状态卡显示「接收中」，并展示延迟/抖动/丢包率/码率等指标。
4. **首次配对成功后双方互存信任**，下次连接无需再输配对码。

### 2.3 切换输出设备

接收中可点击「输出设备」下拉，选择想使用的耳机或扬声器，立即生效。

### 2.4 调整抖动模式

状态卡上的「抖动」下拉提供：

- **低（40ms）**：延迟最低，弱网下可能卡顿。
- **均衡（80ms）**：默认推荐。
- **稳定（150ms）**：弱网下最稳，延迟较高。
- **自动**：根据网络抖动动态调整。

### 2.5 停止接收

点击「停止接收」按钮。状态恢复为空闲。

---

## 3. 发送模式（电脑输出音频）

发送模式把本机系统音频通过局域网传到另一台电脑播放。仅 Windows 可用。

### 3.1 开始发送

1. 在主界面顶部切换角色为「发送端」。
2. 选择采集源（默认为系统输出 WASAPI Loopback）。
3. 点击「开始发送」。
4. **首次开启会弹窗提示**：部分受 DRM 保护的应用音频可能无法采集，属系统限制。确认后不再重复弹窗。

### 3.2 连接接收端

1. 在「发现的接收端」列表中选择目标设备，点击「连接」。
2. 若是首次连接该设备，会弹出配对码输入框，输入接收端屏幕上显示的 6 位配对码。
3. 已信任设备可直接连接，无需输入配对码。
4. 连接成功后状态卡显示「发送中」，展示目标设备、码率、发送包数等指标。

### 3.3 网络断开重连

- 检测到与接收端的连接断开后，发送端会自动按 **5s → 10s → 30s** 三档间隔尝试重连。
- UI 顶部会显示「重连中…」横幅。
- 三次重连失败后状态变为「已断开」，需手动重试。
- 重连期间可随时点击「停止发送」中止。

### 3.4 停止发送

点击「停止发送」按钮，发送端会先通知接收端停止再关闭本地采集。

## 4. 设置

进入「设置」页可调整以下选项。

### 4.1 启动

- **开机自启动**（免费）：开机后自动启动 SoundLink。
- **自启动后自动开启接收/发送**（Pro）：开机后自动进入对应模式（窗口不弹出，静默驻留托盘）。

> 「开机自启动」对所有用户免费；「自动开启收/发」为 **Pro 功能**，免费版下置灰并带「Pro」徽标。免费版开机自启后手动一键即可开始。激活 Pro 后自动收发立即可用（见 §4.6）。

### 4.2 关闭窗口行为

- **每次询问**（默认）：关闭窗口时弹窗询问。
- **最小化到托盘**：关闭窗口时隐藏到系统托盘，进程不退出。
- **退出程序**：关闭窗口即退出。

托盘菜单提供「显示窗口 / 退出」两项。

### 4.3 设备

- **设备名**：mDNS 广播的本机名称，其他设备在发现列表中看到的就是这个名字。修改后立即生效。
- **默认采集源**：发送模式使用的采集源。

### 4.4 日志

- **打开日志目录**：在文件资源管理器中打开日志文件夹（按日轮转的 `soundlink.log.YYYY-MM-DD`）。
- **日志预览**：折叠面板，展示最近 200 行日志，便于快速排查。日志不含密钥/配对码明文。

### 4.5 关于

显示版本号、许可证（MIT）、构建日期、源代码仓库链接。点击仓库链接可通过系统浏览器打开。

### 4.6 授权（Pro）

SoundLink 桌面端核心功能**永久免费**；**Pro 是自动化与便捷性增强**（￥9.99 一次买断，含后续所有版本与 Pro 新功能，最多 3 台设备）。

- **当前状态**：显示「免费版」或「Pro 已激活」。
- **设备指纹**：10 位单向哈希短码（不含隐私信息、不上传），点按复制。下单购买时把它提供给卖家用于签发激活码。
- **激活**：粘贴卖家回发的 `SLPRO-…` 激活码 → 点「激活」，立即解锁，无需重启。校验完全离线，不联网。
- **反激活**：换机前先在此释放授权（清除本机授权），再到新设备用新指纹重新激活。

Pro 功能一览：开机自启 + 启动自动收/发、跨启动自动重连上次设备、记忆 8 台设备（免费 1 台）、多套配置档一键切换、全局快捷键与托盘直控。

> 若显示「本构建不含 Pro（社区版）」，说明你用的是自行编译的社区构建；请从官网或 GitHub Release 下载官方版本后再激活。

### 4.7 配置档（Pro）

把当前「设备 + 抖动模式 + 音量 + 音频参数」保存为命名档位（如「客厅音箱」「桌面耳机」），一键切换。免费版显示示例档（灰色不可点）；激活 Pro 后可保存与应用最多 8 个档位。

## 5. 配对与设备管理

### 5.1 配对码模式

在接收端「设置」可切换：

- **随机模式**（默认）：每次开始接收时生成新的 6 位配对码。
- **固定模式**：使用一个固定 8 位配对码，便于多次输入。固定码安全存储在 OS keyring，不落配置文件。

### 5.2 配对失败锁定

- 连续 5 次输入错误配对码会触发**锁定 60 秒**。
- 锁定期间 UI 显示红色倒计时卡片，无法重试。
- 倒计时结束后自动解锁。

### 5.3 设备身份损坏

- 若 OS keyring 中的设备私钥丢失或损坏，启动时会弹窗警告「设备身份损坏，请重新配对所有设备」。
- 此前已信任的设备需要重新配对一次。

## 6. 常见问题

### 6.1 配对失败 / 找不到设备

- 确认发送端与接收端**连接同一个 Wi-Fi/局域网**。
- 确认 Windows 防火墙允许 SoundLink 通过（首次启动会提示）。
- 企业网络可能开启客户端隔离，导致 mDNS 发现失败；尝试改用家庭网络或手机热点测试。
- 接收端若未点「开始接收」，发送端无法发现它。

### 6.2 听不到声音

- 接收端：检查「输出设备」是否选对了耳机/扬声器；检查系统音量与 SoundLink 状态卡是否显示「接收中」。
- 发送端：检查本机是否有音频正在播放；部分应用默认输出设备可能不同于 SoundLink 采集的设备。
- DRM 受保护内容（部分流媒体/视频）可能无声，属系统限制。

### 6.3 连接不上

- 确认双方角色正确（一端发送、一端接收）。
- 确认配对码未过期（随机码在接收端停止/重启后会变化）。
- 已信任设备直连失败：可能是设备身份变化，尝试在接收端清空信任列表后重新配对。

### 6.4 杂音 / 卡顿

- 切换到「稳定」抖动模式。
- 确认 Wi-Fi 信号良好；2.4GHz 拥挤网络建议改用 5GHz 或有线。
- 关闭占用大量带宽的其他应用。
- 查看状态卡的丢包率/抖动指标；丢包率持续 >10% 说明网络质量差。

### 6.5 DRM 内容无声

- Windows WASAPI Loopback 受系统 DRM 策略约束，部分受保护应用音频无法采集。
- 目前无解决方案，建议改用其他音频源或不受保护的应用。

### 6.6 双击图标启动无响应

- SoundLink 启用了单实例锁定，若已有实例运行，再次双击图标会**聚焦既有窗口**而不是启动新进程。
- 检查系统托盘是否有 SoundLink 图标。

### 6.7 关闭窗口后仍在运行

- 默认关闭行为是「每次询问」。若选了「最小化到托盘」，关闭窗口会隐藏到托盘。
- 在托盘右键菜单选择「退出」可彻底退出。

## 7. 卸载

### 7.1 Windows

1. 「设置 → 应用 → 已安装的应用」中找到 SoundLink，点击卸载。
2. 卸载不会删除用户数据目录 `%APPDATA%\soundlink\`，可手动删除以彻底清理：
   - `app_config.json`：应用配置
   - `trust_store.json`：信任设备列表
   - `device_id.txt`：设备 ID
   - `logs/`：日志文件
3. OS keyring 中的设备私钥与固定配对码需在「凭据管理器 → Windows 凭据」中查找 `soundlink` 条目手动删除。

## 8. 隐私与安全

- SoundLink **不收集任何遥测数据**，不向任何服务器上报。
- 全部网络通信仅发生在用户所在的局域网内。
- 音频流使用 ChaCha20-Poly1305 加密，配对使用 X25519/Ed25519/HKDF-SHA256。
- 设备私钥与固定配对码存储在 OS keyring，不落明文文件。
- 日志不含密钥/配对码明文。

详见 [`docs/privacy.md`](../privacy.md)。
