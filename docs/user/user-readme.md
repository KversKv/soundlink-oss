# SoundLink 用户文档

> 面向**下载安装包直接使用**的终端用户：不编译、不敲命令，从这里了解 SoundLink 能做什么、怎么装、怎么用。
> 开发者（自行编译 / 贡献代码）请从仓库根目录 [README.md](../../README.md) 与 [docs/user/00-index.md](./00-index.md) 进入。

---

## 它是什么

SoundLink 把手机（或另一台电脑）正在播放的声音，通过**家庭/办公室局域网**加密发送到电脑，由电脑输出到耳机、声卡或音箱。一次配对，自动重连；音频不出局域网，零遥测。

- **适用**：听音乐、看长视频
- **不适用**：游戏、连麦等实时互动（延迟不满足）；短视频可能感知轻微延迟

## 下载与安装

1. 从 [GitHub Releases](https://github.com/KversKv/soundlink-oss/releases/latest) 下载最新安装包（Windows 桌面端 / Android 手机端）。
2. Windows 首次运行会弹 **SmartScreen「未知发布者」告警**——安装包未购买代码签名证书，属预期行为。可先用 Release 页提供的 SHA256 校验，再选「仍要运行」：
   ```powershell
   Get-FileHash .\SoundLink-Setup.exe -Algorithm SHA256
   ```
3. 首次启动时，Windows 防火墙弹窗请勾选「**专用网络**」并允许（控制走 TCP 47810，音频走 UDP 47811）。

## 快速上手

### 手机 → 电脑（最常用）

1. 电脑端打开 SoundLink，切到「**接收模式**」，界面显示 8 位配对码与本机地址。
2. 手机与电脑连**同一个 Wi-Fi**（关闭路由器 AP 隔离、勿用访客网络）。
3. 手机端 App 自动发现电脑（搜不到时用「手动 IP」，地址见电脑端「本机地址」），选中后输入 8 位配对码。
4. 首次广播时允许系统的**屏幕采集授权**弹窗（Android MediaProjection 官方能力；受 DRM 保护的内容无法采集）。
5. 手机提示「正在广播」，电脑端即刻出声。配对信息会保存，下次自动重连。

### 电脑 → 电脑

发送端切到「发送模式」，选择采集源（系统环回或测试音源），在「发现 Receiver」中选中对端并输入配对码即可。

## 已知限制（诚实清单）

- **仅局域网**：不支持公网 / NAT 穿透；AP 隔离或访客网络会阻断。
- **DRM 内容不可采**：部分流媒体音频会静音，SoundLink 无法也不试图绕过。
- **单接收端**：一个发送端对应一个接收端。
- **桌面 UI 仅中文**：英文 i18n 在规划中。
- **安装包未代码签名**：Windows SmartScreen 首次运行会告警（见上）。

## 免费版 vs Pro

核心音频流转**永久免费、功能完整**：音质、延迟、码率、Jitter 档位、加密、配对全部不设限。Pro 是自动化与便捷性增强（**￥9.99 一次买断**，含所有后续版本与后续 Pro 新功能，最多 3 台设备，7 日内可退）。

| 能力 | 免费 | Pro |
|---|:---:|:---:|
| 手机→电脑 / 电脑↔电脑 音频流转 | ✅ | ✅ |
| 全码率 + 全 Jitter 档位 + 加密 + 配对 | ✅ | ✅ |
| 记忆已配对设备 | 1 台 | **8 台** |
| 开机自启动 | ✅ | ✅ |
| 启动即自动收/发（静默进入） | — | ✅ |
| 自动重连上次设备（跨启动） | — | ✅ |
| 多套配置一键切换 | — | ✅ |
| 全局快捷键 / 托盘直控 | — | ✅ |
| 快速分辨率切换（Windows） | — | ✅ |

### 如何激活 Pro

1. 桌面端「**设置 → 授权**」区块复制本机**设备指纹**（单向哈希短码，不含隐私、不上传）。
2. 在[淘宝小店](https://e.tb.cn/h.85qPaoTYnCLX5Js?tk=YNdLgzkcHTH)下单，把指纹提供给卖家，获得 `SLPRO-…` 授权码。
3. 回到「设置 → 授权」粘贴授权码，点「激活」，即时生效无需重启。
4. 换机前先在旧机点「反激活」释放名额。

授权**完全离线校验**：不联网、不上传任何信息、无激活服务器（见[隐私政策](../privacy.md)）。

## 常见问题（简版）

- **手机搜不到电脑？** 确认同一网段、关闭 AP 隔离；mDNS 被过滤时用「手动 IP」；检查 Windows 防火墙放行。
- **连上没声音？** 检查电脑端输出设备是否选对；确认播放内容未受 DRM 保护。
- **有延迟？** 默认 Jitter 缓冲 80ms，听音乐看视频属正常体验；游戏连麦不适用。
- 更多见 [08-troubleshooting.md](./08-troubleshooting.md)。
